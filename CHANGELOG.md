## [1.0.2] - 2026-11-14

### Added
- **Standalone Live2D Mascot Plugin `kanbanniang v2.0.0` & Plugin Catalog**: Added the machine-readable `plugins/catalog.json` registry and version-deduplicated GitHub Actions release packaging for `kanbanniang v2.0.0` (26 offline Live2D models, 150 Pio/Tia outfit variants, touch-friendly 7-action toolbar, pointer drag, dark-mode-safe sakura backgrounds, WebGL context recovery, zero-inline strict-CSP boot, and KV head-pats), slimmed to a `~35.5 MiB` pure `.webp` archive (`65%+` smaller) with legacy `kanbanniangSelector` ETL migration support.
- **30+ Language Syntax Highlighting Engine & Heuristic Auto-Detection**: Expanded both the pure-Go server lexer engine and the 3-mode editor with dedicated tokenizers and aliases across Go, JS/TS/JSX/TSX, Python, Rust, Java/Kotlin, C/C++/C#, PHP, Ruby, Lua, GraphQL, Protobuf, HCL/Terraform, SQL, YAML, TOML, Nginx/Apache/Conf, Shell/PowerShell, Diff, HTML/XML, CSS/SCSS, and JSON/JSONC, complete with automatic language inference on unlabeled code blocks and an interactive language picker.
- **Studio 3-Mode Editor Productivity Suite**: Added native Find & Replace (`Ctrl/Cmd+F`, `Ctrl/Cmd+H`, auto-expanding collapsed Instant Render blocks and hidden inline syntax on active matches), a `visualViewport`-aware `/` slash command menu, smart bracket/quote auto-pairing, intelligent rich-HTML paste cleaning (stripping search-engine superscripts/tracking noise, unwrapping lazy-loaded images, and converting code blocks/tables), zero-jitter image reserve sizing, and WYSIWYG file drag-and-drop upload plus floating table row/column controls.
- **Refined Markdown Blockquote & 5-Tone GitHub Callout Rendering**: Upgraded visual hierarchy, nested quote spacing, and light/dark contrast for blockquotes and `[!NOTE]` / `[!TIP]` / `[!IMPORTANT]` / `[!WARNING]` / `[!CAUTION]` callouts across `volo-studio`, `volo-journal`, and the Admin Console editor.

### Changed & Optimized
- **Embedded Admin SPA Slimming & Deterministic Asset Fingerprinting**: Pruned dead CSS selectors and consolidated prose rules via `:is(...)`, compiled static `i18n` lookup keys into compact integer indices, enabled 7-Zip / Zopfli dense Deflate precompression, and switched to deterministic asset filenames with `?v=<hash>` cache-busting queries (`~317.5 KiB` total Gzipped SPA within a `< 380 KiB` budget gate, zero stale build artifacts).
- **Selective Hot-Path Compiler Inlining & Schema `v9` Composite Indexes**: Re-enabled `-l=4` Go function inlining on `internal/render`, `internal/security`, and `pkg/plugin` while keeping all 6 static binaries `~19.4–20.2 MiB` (within a `< 22.00 MiB` budget gate); added Schema `v9` composite indexes (`idx_comments_del_updated`, `idx_follows_sort_created`, `idx_series_sort_created`) and rewrote `hydrateFollowGroups` using SQL `ROW_NUMBER()` window functions.
- **Streaming `256 MiB` Plugin/Theme Packaging & Per-Route Streaming Deadlines**: Upgraded plugin/theme ZIP install and export to streaming I/O with live upload progress and client-side manifest overwrite pre-checks, and extended read/write deadlines via `http.ResponseController` on authenticated media upload, backup, plugin, and migration streams while preserving tight global Slowloris timeouts.

### Security & Fixes
- **Fail-Closed `:::lock` Quote-Depth Isolation & Linear-Time Markdown Scanning**: Hardened `parseChildBlockLine` to enforce exact `expectedQuoteDepth` matching so quoted `> :::` lines inside top-level `:::lock` blocks can never prematurely close secret sections or leak plaintext; eliminated `O(N^2)` rescans on unclosed HTML comments/`<pre>`/`==highlight==`, and restricted bare `<pre><code>` entity decoding to semicolon-terminated entities so `&copy=` query parameters remain intact.
- **Fail-Closed GeoIP Rules, Cross-Platform Path Containment & Defense-in-Depth Headers**: Fixed GeoIP `"block"` rules failing open at runtime (normalizing `"block"` to `"deny"` and evaluating rules fail-closed); hardened Windows custom upload/GeoIP directory validation against drive-less POSIX root paths (`"/etc"`), volume-prefixed system directories, UNC shares, and reserved device names; added pre-bind `AF_UNIX` `sun_path` length checks, sandboxed `Content-Security-Policy` on `/uploads/*`, and native-TLS `Strict-Transport-Security`.
- **JSVM Stack-Overflow Guards & Per-Plugin Async KV Isolation**: Bounded flat expression chains and recursive evaluation depth (`RangeError` instead of Go stack overflow), added Schwartzian pre-stringification and interrupt checks to `Array.prototype.sort`, froze shared builtin prototypes across pooled VMs, and isolated `volo.kv.incrAsync` flushes into per-plugin transactions with hard in-memory key quotas.
- **End-to-End Settings Closure, Cross-DB Restore & Theme/Mobile/Pagination Polish**: Added canonical `301` redirects on `/posts/{slug}` plus template/notification URL alignment for `seo.post_permalink_style`, fixed PostgreSQL backup restore coercion for `users.shield_comments`, skipped redundant lossless VP8L trials on JPEG uploads, seeded `backup.Scheduler` `lastRun` on restart, wired full pagination across Follows Items/Webhooks/GeoIP/Passkeys/Sessions/Tokens, and fixed OS dark-mode accent cascades, mobile nav mask clipping, auto-scrolling active pills, off-canvas rail focus isolation, and wide-screen card footer alignment.

## [1.0.1] - 2026-11-10

### Added
- **Native HTTPS with HTTP/2**: `volo serve` can terminate TLS itself via `VOLO_TLS_CERT_FILE` / `--tls-cert` and `VOLO_TLS_KEY_FILE` / `--tls-key`, with `VOLO_TLS_MIN_VERSION` (`1.2` default or `1.3`), HTTP/2 via ALPN `h2` (HTTP/1.1 fallback), zero-downtime certificate hot reload when the PEM files change (last good certificate kept on errors), and an optional plain-HTTP → HTTPS `308` redirect listener (`VOLO_TLS_HTTP_REDIRECT_ADDR`, e.g. `:80`). `volo healthcheck` probes over HTTPS automatically, and `volo doctor` / the Admin Console doctor add a `tls_certificate` check (unreadable files, mismatched pair, expired or expiring within 14 days). Nginx / Caddy reverse proxying over the Unix socket remains fully supported and recommended for multi-site hosts. HTTP/2 is now kept in all builds (the `nethttpomithttp2` build tag was dropped).
- **Comment Trash, Restore & Auto-Purge**: Deleting a comment (reader self-delete, admin single or batch delete) now moves it to a **Trash** with the full row kept, so a restore is lossless. Permanent deletion (manual, "empty trash", or the retention janitor) physically removes the row together with its reactions; if replies still hang below it, only an anonymous placeholder row is kept with content, nickname, links, IP, masked IP, region, device fingerprint and notification email all erased. Admins can restore, permanently delete, batch restore/purge, or empty the trash (`POST /api/admin/comments/{id}/restore`, `DELETE /api/admin/comments/{id}?purge=1`, batch `restore`/`purge`, `POST /api/admin/comments/trash/empty`). A new `Comment trash retention (days)` setting (default `30`, `0` = manual only) drives a background janitor that purges expired items every 6 hours. Deleted comments that still have visible replies render a localized "This comment has been deleted" placeholder so threads and pagination stay intact.
- **Guest Identity Editing for Comments**: The admin comment edit dialog can now change a comment's nickname, avatar URL and website (validated and normalized), mainly to repair legacy migrated comments; the `@reply-to` name on child replies is synced automatically.
- **Configurable Automated Risk Control, IP/CIDR Whitelist & Full IP Ban Lifecycle**: Added configurable scanner risk-control parameters (`risk_window_seconds=600`, `risk_strike_threshold=5`, 3-tier repeat-offender durations `risk_tier1_minutes=15`, `risk_tier2_minutes=60`, `risk_tier3_minutes=1440` with `0` = permanent ban, and canonical IP/CIDR `risk_whitelist_cidrs` bypassing automatic risk strikes and global WAF rate limits), backed by cross-window database `security_ip_bans.occurrences` escalation. Upgraded IP Ban governance so single/batch **Unban** (`POST /api/admin/security/ip-bans/{id}/unban`, batch `unban`) early-expires bans while preserving historical records; added single-record edit & one-click re-ban (`PATCH /api/admin/security/ip-bans/{id}` supporting `15m / 1h / 24h / 3d / 7d / 30d / permanent / custom minutes`), batch `set_duration` & physical `delete`, one-click `POST /api/admin/security/ip-bans/purge-expired`, `active / expired / all` filter count badges, source (`manual` / `auto_waf`) & cumulative hit (`×N`) columns, and matching `expires_minutes` duration selection on single & batch comment IP bans.
- **Security & Log Retention Policies + One-Click Clear**: Stopped hourly premature deletion of just-expired IP bans; added configurable retention days (`0` = keep permanently) for expired IP bans (`ip_ban_retention_days`, default `30`), admin audit logs (`audit_log_retention_days`, default `90`), and plugin runtime logs (`plugin_log_retention_days`, default `30`), plus one-click clear endpoints and console actions (`DELETE /api/admin/audit-logs`, `DELETE /api/admin/plugins/{id}/logs`).

### Changed
- **Go `1.27.4` Security Toolchain Upgrade**: Upgraded minimum Go toolchain in `go.mod` to `1.27.4` (fixing `net/http` `GO-2026-6859` `MaxBytesReader` header race) and restored `-funcalign=8` linker packing across release builds so all 6 static binaries and downloadable archives stay compact (`< 8 MiB`).
- **Release Packaging Slimmed**: Release archives now contain only the install scripts for their own OS, use reproducible file order/ownership/mtime, and are compressed with 7-Zip at maximum settings (with `gzip -9n` / `zip -9` fallback). The binary size budget was raised from 20 MiB to 21 MiB to accommodate HTTP/2 and native TLS (linux/amd64 ≈ 19.4 MiB). The comment widget gzip budget was raised from 10 KiB to 11 KiB for the keyboard-aware composer and trash placeholders.
- **Version Unification**: Binary, Docker image, `docker-compose.yml` and the admin console package now all report `v1.0.1`.

### Fixed & Improved
- **Mobile & iOS Editing Experience**: iOS Safari no longer auto-zooms when focusing inputs, the Markdown/IR/WYSIWYG editors or the comment composer (16px font on touch devices, viewport zoom left enabled). The comment composer follows the on-screen keyboard and IME candidate bar using `visualViewport` + `translateY` only, keeps textarea focus and caret when toggling fullscreen or tapping toolbar/tab buttons, folds the guest identity row while typing, and locks page scroll on iOS while open. ## [1.0.0-rc6] - 2026-11-09

### Added
- **Unified Pre-Action Chained Interception & Deterministic Plugin Priority Ordering**:
  - **Unified `before_*` Interception Protocol**: All pre-action hooks (`comment.before_create`, `comment.before_update`, `user.before_register`, `user.before_update_profile`, `article.before_save`, `page.before_save`, `media.before_upload`, and custom `*.before_*` hooks) share a single chained pipeline supporting `volo.reject(reason, code)` (`return` or `throw` without tripping the circuit breaker), `{ allow: false, reason, code }`, `{ action: "reject", reason }`, `return false`, non-destructive partial payload mutation, and monotonic `status: "pending"` moderation ratcheting.
  - **Plugin Priority & Chain Sorting**: Every plugin carries an execution `priority` (`manifest.json` `"priority"`, default `100`, range `-1000..10000`; smaller runs earlier, ties broken by `id`) persisted in `plugins.config_json`. Controls deterministic execution order across **all hooks, UI slots, render cache digests, and same-type `ProviderRegistry` chains** (`antispam`, `notifier`, `federation`, `oidc`, `storage`), with one-click `↑` / `↓` / Move-Top reordering (`POST /api/admin/plugins/reorder`) and numeric priority editing (`PATCH /api/admin/plugins/{id}/priority`) in the Admin Plugin Center.
- **5-Stage Plugin Lifecycle & Min-Heap `CronRegistry`**:
  - Full 5-stage lifecycle callbacks (`onInstall` -> `onEnable` -> `onConfigChange` -> `onDisable` -> `onUninstall`) across JS and compiled Go plugins, with `Uninstall` invoking `onUninstall()` best-effort before wiping `plugin_kv`, `plugins`, and `./plugins/<id>` on disk.
  - Built-in min-heap `CronRegistry` (`pkg/plugin/scheduler.go`) supporting declarative `manifest.json` `"cron"` jobs and dynamic `volo.cron.register(name, intervalSec, handlerName, immediate?)` / `unregister` / `list`, bounded worker concurrency, panic recovery, status badges, and one-click manual execution (`POST /api/admin/plugins/{id}/trigger-cron`).
- **Native CSR/Double-Array Aho-Corasick `pkg/wordfilter` & Official `sensitive-words` Plugin**:
  - Zero-CGO `pkg/wordfilter` (`volo.wordFilter` SDK) featuring 32-bit CSR / Double-Array Aho-Corasick matching (`O(N)` zero-heap hot-path scanning), 4-pass full-text anti-obfuscation normalization (Simplified/Traditional folding, fullwidth/halfwidth, Zalgo combining-mark stripping, Mathematical/Enclosed/Cyrillic/Greek homoglyph folding, zero-width/separator stripping, and character deduplication), and longest-span `allow` overrides.
  - Official `./plugins/sensitive-words` plugin (`priority: 20`) bundling a compact `281 KiB` prefix/tag delta-compressed lexicon (`houbb_base.txt.gz`, 6 category toggles), `allowlist.txt`, SSRF-safe remote wordlist sync + ETag cache, and `DELETE /plugins/sensitive-words/api/remote-cache`.
  - **Strict Union/Merge with Host Settings & Non-Destructive `*` Display Masking**: Works additively with host `reading.blocked_keywords` / `allowed_keywords` across reader email OTP preflight (`POST /api/v1/reader/send-code`), registration, OIDC auto-provisioning, reader/editor profile updates (`PATCH /api/v1/reader/profile`, `PUT /api/admin/me`), and comment creation/editing (including `author_url` and post-hook `content_md` re-screening). Enabling `mask_existing` (`volo.wordFilter.setSanitizer`) or host `reading.builtin_spam_filter` non-destructively masks pre-existing historical comments, recent-comment excerpts, guest impersonator handles, and legacy reader nicknames with `*` at render time (piercing split inline HTML tags while preserving URLs/entities, allowlisted phrases, and verified staff/author display names, with instant cache coherence).
  - **`tag_list` (`token_list`) Config Schema & Scalable Chip Editor**: Added `"tag_list"` (`"token_list"` alias) to plugin and theme `config_schema`, migrating `sensitive-words` word lists to a compact multi-column chip editor with progressive DOM capping, live search filtering, comment-aware bulk paste deduplication, and 1:1 live-synced batch text editing.

  - Schema `v7` migration, interactive Step-Up password verification for backup exports and OIDC account linking, and complete external `./locales/zh-TW.json` and `./locales/ja-JP.json` packs.
