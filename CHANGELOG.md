## [1.0.0-rc6] - 2026-11-09

### Added / 新增特性
- **Unified Pre-Action Chained Interception & Deterministic Plugin Priority Ordering**:
  - **Unified `before_*` Interception Protocol**: All pre-action hooks (`comment.before_create`, `comment.before_update`, `user.before_register`, `user.before_update_profile`, `article.before_save`, `page.before_save`, `media.before_upload`, and custom `*.before_*` hooks) share a single chained pipeline supporting `volo.reject(reason, code)` (`return` or `throw` without tripping the circuit breaker), `{ allow: false, reason, code }`, `{ action: "reject", reason }`, `return false`, non-destructive partial payload mutation, and monotonic `status: "pending"` moderation ratcheting.
  - **Plugin Priority & Chain Sorting**: Every plugin carries an execution `priority` (`manifest.json` `"priority"`, default `100`, range `-1000..10000`; smaller runs earlier, ties broken by `id`) persisted in `plugins.config_json`. Controls deterministic execution order across **all hooks, UI slots, render cache digests, and same-type `ProviderRegistry` chains** (`antispam`, `notifier`, `federation`, `oidc`, `storage`), with one-click `↑` / `↓` / Move-Top reordering (`POST /api/admin/plugins/reorder`) and numeric priority editing (`PATCH /api/admin/plugins/{id}/priority`) in the Admin Plugin Center.
- **5-Stage Plugin Lifecycle & Min-Heap `CronRegistry`**:
  - Full 5-stage lifecycle callbacks (`onInstall` -> `onEnable` -> `onConfigChange` -> `onDisable` -> `onUninstall`) across JS and compiled Go plugins, with `Uninstall` invoking `onUninstall()` best-effort before wiping `plugin_kv`, `plugins`, and `./plugins/<id>` on disk.
  - Built-in min-heap `CronRegistry` (`pkg/plugin/scheduler.go`) supporting declarative `manifest.json` `"cron"` jobs and dynamic `volo.cron.register(name, intervalSec, handlerName, immediate?)` / `unregister` / `list`, bounded worker concurrency, panic recovery, status badges, and one-click manual execution (`POST /api/admin/plugins/{id}/trigger-cron`).
- **Native CSR/Double-Array Aho-Corasick `pkg/wordfilter` & Official `sensitive-words` Plugin**:
  - Zero-CGO `pkg/wordfilter` (`volo.wordFilter` SDK) featuring 32-bit CSR / Double-Array Aho-Corasick matching (`O(N)` zero-heap hot-path scanning), 4-pass full-text anti-obfuscation normalization (Simplified/Traditional folding, fullwidth/halfwidth, Zalgo combining-mark stripping, Mathematical/Enclosed/Cyrillic/Greek homoglyph folding, zero-width/separator stripping, and character deduplication), and longest-span `allow` overrides.
  - Official `./plugins/sensitive-words` plugin (`priority: 20`) bundling a compact `281 KiB` prefix/tag delta-compressed lexicon (`houbb_base.txt.gz`, 6 category toggles), `allowlist.txt`, SSRF-safe remote wordlist sync + ETag cache, and `DELETE /plugins/sensitive-words/api/remote-cache`.
  - **Strict Union/Merge with Host Settings & Non-Destructive `*` Display Masking**: Works additively with host `reading.blocked_keywords` / `allowed_keywords` across reader email OTP preflight (`POST /api/v1/reader/send-code`), registration, OIDC auto-provisioning, reader/editor profile updates (`PATCH /api/v1/reader/profile`, `PUT /api/admin/me`), and comment creation/editing (including `author_url` and post-hook `content_md` re-screening). Enabling `mask_existing` (`volo.wordFilter.setSanitizer`) or host `reading.builtin_spam_filter` non-destructively masks pre-existing historical comments, recent-comment excerpts, guest impersonator handles, and legacy reader nicknames with `*` at render time (piercing split inline HTML tags while preserving URLs/entities, allowlisted phrases, and verified staff/author display names, with instant cache coherence).
  - **`tag_list` (`token_list`) Config Schema & Scalable Chip Editor**: Added `"tag_list"` (`"token_list"` alias) to plugin and theme `config_schema`, migrating `sensitive-words` word lists to a compact multi-column chip editor with progressive DOM capping, live search filtering, comment-aware bulk paste deduplication, and 1:1 live-synced batch text editing.
- **Schema `v7`, Step-Up Security & Complete `zh-TW` / `ja-JP` Language Packs**:
  - Schema `v7` migration, interactive Step-Up password verification for backup exports and OIDC account linking, and complete external `./locales/zh-TW.json` and `./locales/ja-JP.json` packs.

### Changed & Fixed / 优化与安全加固
- **Zero-Bloat Pure-Go Drivers & Single-Pass HTML5 AST Sanitizer**: Replaced `pgx/v5` with a first-party pure-Go PostgreSQL v3 wire driver (`internal/db/pgwire`, supporting SCRAM-SHA-256, TLS, Extended & Simple Query protocols) and replaced `bluemonday` with a single-pass `golang.org/x/net/html` AST sanitizer (`internal/render/htmlsanitize.go`), cutting binary size to **`~17.3 MiB`** (`< 20 MiB` budget) and downloadable archives to **`< 8 MiB`**.
- **Plugin Center FLIP Motion & Modal Focus-Ring Polish**: Unified Plugin Center `↑` / `↓` / Move-Top / numeric priority reordering with optimistic FLIP spring transitions (`useFlipList`), eliminated execution-order column wrapping, and prevented `3px` focus-ring clipping inside modal bodies and scrollable sortable option lists.
- **Sandbox, File-Serving & CodeQL SAST Zero-Alert Hardening**: Confined external theme and plugin static assets with `os.OpenInRoot` against symlink escapes, closed default-URL outbound allowlist bypasses on remote wordlist sync, added `hooks:<domain>.*` wildcard permission validation, and resolved all Go and JavaScript/TypeScript CodeQL Code Scanning alerts (upload path containment, redirect target validation, guest cookie `Secure` flow, PGv3 TLS/wire auth, and editor DOM/URL sanitization).

## [1.0.0] - 2026-11-08

### Added / 新增特性
- **Pure-Go Single-Binary Engine & 6-Target Static Matrix (`CGO_ENABLED=0`)**:
  - Cross-platform static single binary (`< 20 MiB` on `linux/amd64` & `arm64`, `< 21 MiB` across all **6 supported release targets**: `linux/amd64`, `linux/arm64`, `darwin/amd64`, `darwin/arm64`, `windows/amd64`, and `windows/arm64`) built with Go `1.27.3` (`GOEXPERIMENT=nojsonv2`), `< 35 MiB` live `VmRSS` (measured `25.17 MiB`), lock-free CAS monotonic ID generator, TCP & Unix Domain Socket listeners (`--socket-mode` / `--socket-group` / `VOLO_SOCKET_MODE` / `VOLO_SOCKET_GROUP`), graceful `SIGTERM` shutdown (`VOLO_SHUTDOWN_TIMEOUT_SEC`), `/healthz` (`{"status","database","uptime_sec"}`), and native Distroless `volo healthcheck`.
  - Multi-layer configuration hierarchy (`CLI Flags > OS VOLO_* Env > .env > Admin DB Settings > Built-in Defaults`), leaving `VOLO_DB_DRIVER` unset by default so the `/setup` wizard's `AES-256-GCM` sealed `data/db.json` (`SQLite` / `PostgreSQL` / `MySQL`) persists across container and service restarts, plus `HKDF-SHA256` subkey derivation.
  - Unified pure-Go `Dialect` layer supporting **SQLite WAL** (`modernc.org/sqlite` with physically separated writer & `query_only=ON` reader pools and bounded `4 MiB` page cache), **PostgreSQL** (pure-Go PGv3 wire driver `pgwire`, including `--db-simple-protocol` / `VOLO_DB_SIMPLE_PROTOCOL` for PgBouncer/Supabase poolers), and **MySQL 8+ / MariaDB / TiDB**, backed by idempotent schema migrations (`v1`–`v7`).
- **Normalized Schema (`v6`), Scale APIs & Streaming Migration / Backup**:
  - **33 normalized data tables** (+ `schema_migrations`) across **9 atomic hot-reload settings domains** (`site`, `reading`, `feed`, `seo`, `storage`, `appearance`, `notifications`, `security`, `backup`): direct `articles.category_id`, standalone Markdown `pages` (with custom `template`) and hierarchical `nav_items`, `series`, `books` (`POST /api/admin/{categories,books}/reorder`), `webhook_deliveries` bounded history, `analytics_daily` / `analytics_top_items`, `redirects`, and `plugin_kv`.
  - Automatic `/sitemap.xml` `<sitemapindex>` sharding when public URLs exceed `10,000` entries (`/sitemap-1.xml`, `/sitemap-2.xml`, …) and paginated two-stage `/api/v1/search?q=...&page=...` endpoint.
  - Two-phase streaming legacy 15-table ZIP/JSON ETL importer (`volo import-legacy` with `--dry-run`, `--old-site-url`, `--new-site-url`, `--storage-local` & Web Setup/System uploader) preserving `.html` permalinks via `301` redirects, plus cross-DB streaming `NDJSON` + media ZIP backup/restore (`volo backup create/restore` across `SQLite ⇄ PostgreSQL ⇄ MySQL`) and scheduled local + S3/WebDAV rolling backups.
- **Dynamic Stealth Admin Path, Multi-DB GeoIP Coexistence & Sovereign Identity**:
  - **Dynamic Stealth Admin Path** (`security.admin_path` / `dynamic_login_path`) with zero-downtime hot-reload without restarting the server, returning indistinguishable `404` responses on default probe paths when customized.
  - **Offline GeoIP Multi-Database Coexistence**: side-by-side support for `GeoLite2-City.mmdb` + `GeoLite2-Country.mmdb` + `GeoLite2-ASN.mmdb` (tier-ranked so non-geographic ASN/ISP DBs never shadow City/Country precision) + `ip2region` IPv4/IPv6 `.xdb`, hot-reloadable `security.geoip_dir`, configurable `geo_default_action` & `geo_unknown_action` (`allow | deny`), anti-self-lockout verification, and emergency `VOLO_GEO_ACCESS_ENABLED=false` bypass.
  - `admin` / `editor` (author-isolated comment moderation) / `reader` RBAC, `Argon2id` password hashing (with transparent `PBKDF2` upgrade), WebAuthn Passkeys, TOTP + recovery codes, session management, scoped `volo_pat_*` API tokens, 3-tier self-healing HMAC `GuestPassport` + peppered `env_fp` + stateless `SHA-256` PoW + one-click guest comment claiming, and `/32` IPv4 & `/64` IPv6 WAF rate limiting.
- **3-Mode Studio Editor, 10-Surface Privacy Perimeter & Media Pipeline**:
  - Embedded Preact + Signals 5-workspace Studio Console featuring radial pop-out & curve-following interactive overview charts and the lazy-loaded **3-Mode Studio Editor**: **IR** (Instant Rendering with HTML/GFM table widgets, custom app deep-link anchors, `==highlight==` / `^sup^` / `~sub~`, KaTeX, Mermaid, interactive task checkboxes, tall-image scroll stabilization & `~~~` fences), **WYSIWYG** (dirty-guarded rich round-trip editing with `<audio>`/`<video>` cursor landing pads), and **SV** (split-view synchronized preview), plus arbitrary webpage rich `text/html` copy-paste with automatic base64 image upload, GFM table `Tab`/`Shift-Tab` cell navigation, `[toc]` & media embeds, `.md`/`.html`/Rich HTML export, and built-in browser voice recording.
  - `ContentVisibilityGuard` enforcing zero leakage of password-protected posts and `:::lock` blocks across all 10 surfaces plus stateless timed `ShareToken` preview links and BREACH-safe HTTP dynamic compression.
  - Privacy-first media pipeline (`<= 64 MP` decompression-bomb cap, EXIF orientation normalization, 100% GPS/EXIF metadata stripping, adaptive pure-Go WebP encoding, intrinsic width/height zero-CLS injection, pure-Go AWS SigV4 S3/R2/MinIO upload, and 9-scope orphan media pruning).
- **Extensible Theme SDK & Sandboxed ES6 Plugin Ecosystem**:
  - **Plugin Extensibility**: first-party pure-Go ES6 sandboxed VM (`runtime: "goja"` compatible), `volo.registerDirective(name, fn)` custom Markdown directives, `type: "secret"` (and `secret: true`) `AES-256-GCM` encrypted/masked fields in `config_schema`, `GET /api/admin/plugins/{id}/export` clean `.zip` export, `POST /api/admin/plugins/install?overwrite=true` in-place ZIP upgrade, automatic `federation` dispatch on article publish/update, and `./plugins/kanbanniang` companion plugin.
  - **Theme Extensibility**: built-in `volo-studio` & external `./themes/volo-journal` themes, `{{customVar ...}}` (`Site.CustomVars` Admin UI), `page_templates` per-page layout selector, `Reading.ListStyle` (`summary | title_only | full`), standalone frameless `error.html` override (`{{define "layout"}}`), and clean starter `.zip` export (`GET /api/admin/themes/{id}/export`).
- **Multi-OS Service Installers, Auto-Rollback Upgrades & Reverse Proxy Templates**:
  - `scripts/install-service.sh` (Linux `systemd` system/user, `OpenRC` `/run/volo/volo.pid`, macOS `launchd`) and `scripts/install-service.ps1` (native Windows Service `sc.exe` via `svc_windows.go` alongside `NSSM` & Scheduled Task fallback, `-Action Logs`, and `-Mirror` acceleration fallback), both featuring automatic pre-upgrade database backup (`--skip-backup` / `-SkipBackup` opt-out), `volo.bak` binary preservation, and post-upgrade `volo healthcheck` verification with automatic rollback on failure.
  - Ready-to-use `systemd` (`ReadWritePaths` override guidance), `OpenRC`, Docker Compose (`volo_data:/app/data`), Nginx (TCP & Unix Socket `--socket-mode 0660 --socket-group www-data`), Caddy v2, Traefik v3, and Apache httpd configurations, GitHub Actions CI/Release/Security/Benchmark pipelines, full bilingual (`zh-CN` & `en-US`) documentation, and **Apache License 2.0** (`LICENSE` & `THIRD_PARTY_NOTICES.md`).
