## [1.0.0] - 2026-11-09

### Added / 新增特性
- **Real-Time Non-Destructive ImageView Rendering (`/uploads/...?...`)**:
  - **Dual Qiniu + KV Query Syntax**: Simultaneously supports Qiniu Cloud native path parameters (`?imageView2/<mode>/w/960/h/540/format/webp/q/85/interlace/1/colors/128/strip/ignore-error/1`) and standard key-value query parameters (`?mode=1&w=960&h=540&format=webp&interlace=1&q=85&colors=128&strip&meta-keep-list=...&ignore-error=1`) in any combination across resize/crop modes `0`–`5` (`fit`, `fill`, `lfit`, `mfit`, `pad`, `crop`), output formats `jpg`/`png`/`webp`/`avif` (pure-Go fallback to `webp` with `X-Volo-Format-Fallback: avif->webp`), quality `1`–`100`, palette quantization `2`–`256`, EXIF orientation auto-righting, and `ignore-error=1` graceful fallback.
  - **Zero-Mutation Passthrough, Coalescing & Orphan/CLS Linkage**: Unparameterized `/uploads/...` requests stream original files directly with zero overhead and never modify source uploads on disk or S3; parameterized transforms run through `singleflight` request coalescing + a strict `8 MiB` byte-bounded LRU cache keyed on `(path, mtime, size, spec)` + strong `ETag` / `304 Not Modified`, while `LookupMediaDims` predicts transformed `width`/`height` for zero-CLS rendering and `orphan.go` strips query/fragment suffixes so parameterized Markdown image references are never falsely flagged as orphans.
- **Schema `v8` — Discourse-Style Account Ban/Unban, Timed Suspension, Mute & Reversible Comment Shielding**:
  - Added `ban_until`, `muted_until`, `ban_reason`, `shield_comments`, and `shield_text` to `users` (`v8` idempotent migration across SQLite, PostgreSQL, and MySQL) with Admin Console Users management (`GET`/`PATCH /api/admin/users`) and one-click Comments moderation actions.
  - Supports permanent or timed account bans (immediately revoking active sessions and PATs, with automatic reactivation upon expiry) and permanent or timed mutes (allowing login and reading while blocking new/edited comments and reactions with localized expiry notices).
  - **Reversible Historical Comment Shielding**: Enabling `shield_comments` non-destructively replaces all public comments by a banned or muted user with customizable placeholder copy (`shield_text`) at render time while preserving original `comments.content_md` and reply trees in the database — unbanning/unmuting or timer expiration immediately restores original comments intact.
- **Per-Identity Comment Bounds, Vertical Height-Bombing Defense & Fullscreen Reply Editor**:
  - **Configurable Per-Identity Bounds**: Enforces default minimum `2` runes, `512` max runes (`16` max lines) for guests, `1024` max runes (`24` max lines) for registered readers, and `4096` max runes (`64` max lines) for staff (`admin`/`editor`), all dynamically configurable in Admin Console `reading` settings and exposed via `/api/v1/comments`.
  - **Multi-Layer Height-Bombing Defense**: Normalizes Unicode line separators, caps Zalgo combining-mark towers (`<= 3` per base rune), collapses invisible blank filler lines (Braille blank `U+2800`, Hangul filler `U+3164`/`U+FFA0`, ZWSP, lone `\` hard breaks, empty list markers), collapses `3+` consecutive newlines, deduplicates empty blockquotes/rules, demotes comment `h1`–`h3` -> `h4`, caps consecutive `<br>` tags at `2`, bounds comment `<img>`/`<pre>` CSS heights, and auto-folds tall comments with expand/collapse toggles.
  - **Enhanced Safe Reply Markdown Editor**: Upgraded public comment editor in `volo-studio` and `volo-journal` with formatting toolbar (`bold`, `italic`, `strike`, inline/fenced code, quote, list, safe link), sanitized live preview (`POST /api/v1/comments/preview`), distraction-free fullscreen editing (`Esc` exit), and live rune/line counters.

### Changed, Hardened & Slimmed / 性能瘦身、全配置闭环与安全加固
- **Sub-`20.00 MiB` Pure-Go Binary Slimming Across All 6 Targets**: Replaced `encoding/xml` with a zero-reflection streaming parser (`internal/tinyxml`), replaced `net/smtp` + `net/mail` with a pure-Go STARTTLS/SMTPS client and RFC 5322 validator (`internal/notify`), eliminated generic `sqlx.Get`/`Select` instantiations in favor of `GetInto`/`SelectInto`, and built with `GOEXPERIMENT=nojsonv2` + `-funcalign=8` — keeping **every release binary across all 6 OS/Arch targets strictly `< 20.00 MiB`** (`linux/amd64` ~`19.1 MiB`, warm `VmRSS` ~`24.2 MiB < 35.00 MiB`).
- **End-to-End Settings & Security Closure**: Wired all 4 `seo.post_permalink_style` templates (`/posts/{slug}`, `/archives/{slug}`, `/p/{slug}`, `/{year}/{month}/{slug}` + `.md` + instant cache/search rebuild), `security.totp_remember_days = 0` & `totp_window_steps`, `NotifyCommentReplyApproved` on pending reply approval, `storage.max_upload_mb` multipart enforcement, `feed.item_count` in `/podcast.xml`, live `WAF.UpdateConfig`, and `X-Volo-Console: 1` anti-CSRF gating on `/api/admin/me`.
- **Plugin Sandbox & Write-Behind KV Hardening**: Added streaming depth/key/element-bounded `JSON.parse` & `goToJSValueBounded`, AST recursion depth limits (`128`), frozen builtin prototypes + `snapshotPostInit`/`restorePostInit` pooled VM isolation, `ErrExecutionTimeout` sentinel preservation, binary-safe `btoa`/`atob` & base64 `volo.http.fetch`, write-behind `volo.kv.incrAsync`/`flush` hub eliminating hot-path SQLite contention, and `kanbanniang` `ja-JP` localization.
- **Unix Domain Socket, Service Installers & Release CI Gate**: Added `--unix-socket` alias, parent `EvalSymlinks` + leaf `Lstat` symlink defense, `--socket-group`/`--socket-mode` enforcement, read-only `volo healthcheck`, shell-free OpenRC `load_volo_env()` (eliminating `. /etc/volo/volo.env` RCE), `systemd` `RuntimeDirectory=volo` + `--bin-dir` vs `--data-dir` privilege separation, Windows `icacls`/`sc.exe` exit checks, and automated GitHub Actions `verify` gate distinguishing stable (`latest`) vs preview (`prerelease`) releases.

## [1.0.0-rc6] - 2026-11-09

### Added / 新增特性
- **Unified Pre-Action Chained Interception & Deterministic Plugin Priority Ordering**:
  - **Unified `before_*` Interception Protocol**: All pre-action hooks (`comment.before_create`, `comment.before_update`, `user.before_register`, `user.before_update_profile`, `article.before_save`, `page.before_save`, `media.before_upload`, and custom `*.before_*` hooks) share a single chained pipeline supporting `volo.reject(reason, code)` (`return` or `throw` without tripping the circuit breaker), `{ allow: false, reason, code }`, `{ action: "reject", reason }`, `return false`, non-destructive partial payload mutation, and monotonic `status: "pending"` moderation ratcheting.
  - **Plugin Priority & Chain Sorting**: Every plugin carries an execution `priority` (`manifest.json` `"priority"`, default `100`, range `-1000..10000`; smaller runs earlier, ties broken by `id`) persisted in `plugins.config_json`. Controls deterministic execution order across **all hooks, UI slots, render cache digests, and same-type `ProviderRegistry` chains** (`antispam`, `notifier`, `federation`, `oidc`, `storage`), with one-click `↑` / `↓` / Move-Top reordering (`POST /api/admin/plugins/reorder`) and numeric priority editing (`PATCH /api/admin/plugins/{id}/priority`) in the Admin Plugin Center.
- **5-Stage Plugin Lifecycle & Min-Heap `CronRegistry`**:
  - Full 5-stage lifecycle callbacks (`onInstall` -> `onEnable` -> `onConfigChange` -> `onDisable` -> `onUninstall`) across JS and compiled Go plugins, with `Uninstall` invoking `onUninstall()` best-effort before wiping `plugin_kv`, `plugins`, and `./plugins/<id>` on disk.
  - Built-in min-heap `CronRegistry` (`pkg/plugin/scheduler.go`) supporting declarative `manifest.json` `"cron"` jobs and dynamic `volo.cron.register(name, intervalSec, handlerName, immediate?)` / `unregister` / `list`, bounded worker concurrency, panic recovery, status badges, and one-click manual execution (`POST /api/admin/plugins/{id}/trigger-cron`).
- **Native CSR/Double-Array Aho-Corasick `pkg/wordfilter` & Official `sensitive-words` Plugin**:
  - Zero-CGO `pkg/wordfilter` (`volo.wordFilter` SDK) featuring 32-bit CSR / Double-Array Aho-Corasick matching (`O(N)` zero-heap hot-path scanning), 4-pass full-text anti-obfuscation normalization (Simplified/Traditional folding, fullwidth/halfwidth, Zalgo combining-mark stripping, Mathematical/Enclosed/Cyrillic/Greek homoglyph folding, zero-width/separator stripping, and character deduplication), and longest-span `allow` overrides.
  - Official `./plugins/sensitive-words` plugin (`priority: 20`) bundling a compact `281 KiB` prefix/tag delta-compressed lexicon (`houbb_base.txt.gz`, 6 category toggles), `allowlist.txt`, SSRF-safe remote wordlist sync + ETag cache, and `DELETE /plugins/sensitive-words/api/remote-cache`.
  - **Strict Union/Merge with Host Settings & Non-Destructive `*` Display Masking**: Works additively with host `reading.blocked_keywords` / `allowed_keywords` across reader email OTP preflight (`POST /api/v1/reader/send-code`), registration, OIDC auto-provisioning, reader/editor profile updates (`PATCH /api/v1/reader/profile`, `PUT /api/admin/me`), and comment creation/editing (including `author_url` and post-hook `content_md` re-screening). Enabling `mask_existing` (`volo.wordFilter.setSanitizer`) or host `reading.builtin_spam_filter` non-destructively masks pre-existing historical comments, recent-comment excerpts, guest impersonator handles, and legacy reader nicknames with `*` at render time (piercing split inline HTML tags while preserving URLs/entities, allowlisted phrases, and verified staff/author display names, with instant cache coherence).
  - **`tag_list` (`token_list`) Config Schema & Scalable Chip Editor**: Added `"tag_list"` (`"token_list"` alias) to plugin and theme `config_schema`, migrating `sensitive-words` word lists to a compact multi-column chip editor with progressive DOM capping, live search filtering, comment-aware bulk paste deduplication, and 1:1 live-synced batch text editing.
- **Schema `v7`, Step-Up Security & Complete `zh-TW` / `ja-JP` Language Packs**:
  - Schema `v7` migration, interactive Step-Up password verification for backup exports and OIDC account linking, and complete external `./locales/zh-TW.json` and `./locales/ja-JP.json` packs.

### Changed & Fixed / 优化与安全加固
- **Zero-Bloat Pure-Go Drivers & Single-Pass HTML5 AST Sanitizer**: Replaced `pgx/v5` with a first-party pure-Go PostgreSQL v3 wire driver (`internal/db/pgwire`, supporting SCRAM-SHA-256, TLS, Extended & Simple Query protocols) and replaced `bluemonday` with a single-pass `golang.org/x/net/html` AST sanitizer (`internal/render/htmlsanitize.go`), cutting binary size to **`~17.3 MiB`** (`< 20 MiB` budget) and downloadable archives to **`< 8 MiB`**.
- **Plugin Center FLIP Motion & Modal Focus-Ring Polish**: Unified Plugin Center `↑` / `↓` / Move-Top / numeric priority reordering with optimistic FLIP spring transitions (`useFlipList`), eliminated execution-order column wrapping, and prevented `3px` focus-ring clipping inside modal bodies and scrollable sortable option lists.
- **Sandbox, File-Serving & CodeQL SAST Zero-Alert Hardening**: Confined external theme and plugin static assets with `os.OpenInRoot` against symlink escapes, closed default-URL outbound allowlist bypasses on remote wordlist sync, added `hooks:<domain>.*` wildcard permission validation, and resolved all Go and JavaScript/TypeScript CodeQL Code Scanning alerts (upload path containment, redirect target validation, guest cookie `Secure` flow, PGv3 TLS/wire auth, and editor DOM/URL sanitization).

  - Cross-platform static single binary (`< 20 MiB` on `linux/amd64` & `arm64`, `< 21 MiB` across all **6 supported release targets**: `linux/amd64`, `linux/arm64`, `darwin/amd64`, `darwin/arm64`, `windows/amd64`, and `windows/arm64`) built with Go `1.27.3` (`GOEXPERIMENT=nojsonv2`), `< 35 MiB` live `VmRSS` (measured `25.17 MiB`), lock-free CAS monotonic ID generator, TCP & Unix Domain Socket listeners (`--socket-mode` / `--socket-group` / `VOLO_SOCKET_MODE` / `VOLO_SOCKET_GROUP`), graceful `SIGTERM` shutdown (`VOLO_SHUTDOWN_TIMEOUT_SEC`), `/healthz` (`{"status","database","uptime_sec"}`), and native Distroless `volo healthcheck`.
